# URECA Results

This directory is reserved for real experiment outputs produced by the `ureca_` executables and scripts on the `ureca/experiment-suite` branch.

No synthetic trajectory or summary data is committed here.

Expected runtime outputs include:

- `summary.csv` or experiment-specific summary files
- per-run trajectory CSVs
- plot PNGs created by `scripts/ureca_plot_results.py`

If TrajOpt cannot run in the current environment, leave this directory as templates only.
